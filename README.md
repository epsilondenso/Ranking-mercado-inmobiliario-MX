# Ranking del mercado inmobiliario en México

Proyecto de análisis de datos que procesa anuncios inmobiliarios para generar un ranking de colonias a partir de métricas como precio por m², variabilidad de precio y edad de los anuncios.


## Estructura

- `src/`: pipeline y funciones.
- `data/`: datos crudos y procesados.
- `notebooks/`: exploración.
- `config/`: configuración.

## Stack

Python, Pandas, NumPy, Matplotlib y Seaborn.
